# 🎯 InterviewVerse AI

> An AI-powered interview preparation platform designed to help students practice interviews, improve their answers, and build confidence.

## 📌 Overview

InterviewVerse AI is a full-stack AI-powered interview coaching application built using the MERN stack.

The platform allows users to register and securely log in, practice interview questions, receive AI-generated interview interactions, and improve their interview preparation through a structured experience.

The main goal of this project is to provide students and job seekers with an interactive platform for practicing technical and HR interviews.

---

## ✨ Features

- 🔐 User Registration & Login
- 🔒 Secure Password Hashing using bcrypt
- 🎟️ JWT-based Authentication
- 🤖 AI-powered Interview Experience
- 💬 Interactive Interview Questions
- 📊 User-focused Interview Practice
- 🌐 Full-stack MERN Architecture
- 🗄️ MongoDB Database Integration
- 📡 REST API-based Backend
- 🧪 API Testing using Postman
- 📱 Responsive Frontend Interface
